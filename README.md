 Livraria Digital - Full Stack Web & API RESTAplicação web completa para gestão e consulta de catálogo de livros, desenvolvida como projeto para o curso do SENAI na disciplina de Linguagem de Marcação e Desenvolvimento Web.📸 Sobre o ProjetoA Livraria Digital é uma plataforma que integra uma interface moderna e responsiva a uma API RESTful em Java. O sistema permite aos usuários navegar por categorias, pesquisar livros por título ou autor, adicionar obras ao carrinho e realizar reservas.🛠️ Tecnologias UtilizadasFront-endHTML5 & CSS3Tailwind CSS (Design responsivo e estilização utilitária)React.js (Componentização e gerenciamento de estado via CDN)Back-endJava 25 (Utilizando os mais recentes recursos da JVM)Spring Boot 3.xSpring Web (API REST)Spring Data JPA (Persistência de dados)H2 Database / MySQL (Banco de dados)Maven (Gerenciador de dependências)✨ Funcionalidades[x] Catálogo Interativo: Exibição de capas, autores, preços e detalhes dos livros.[x] Busca e Filtros: Pesquisa dinâmica por título, autor e categorias (Ficção, Não-Ficção, Didáticos, etc.).[x] Carrinho de Compras: Adição, alteração de quantidade e remoção de itens com cálculo de total em tempo real.[x] Formulário de Reservas: Agendamento de retiradas e reservas VIP.[x] API RESTful: Endpoints completos para operações de CRUD (Create, Read, Update, Delete).🔗 Endpoints da API (Back-end)MétodoEndpointDescriçãoGET/api/livrosRetorna todos os livros cadastradosGET/api/livros/{id}Retorna os detalhes de um livro específicoPOST/api/livrosCadastra um novo livro na base de dadosPUT/api/livros/{id}Atualiza as informações de um livroDELETE/api/livros/{id}Remove um livro do catálogo🚀 Como Executar o Projeto1. Executando o Back-end (Spring Boot)Pré-requisitos:Java JDK 25 instalado.IDE configurada (IntelliJ IDEA recomendado) ou Maven no terminal.Passo a passo:Abra o projeto da API no IntelliJ IDEA.Certifique-se de que a JDK 25 está selecionada nas configurações de SDK do projeto.Execute a classe principal da aplicação ou utilize o comando Maven no terminal:./mvnw spring-boot:run
A API estará acessível em: http://localhost:8080/api/livrosNota para Java 25: Caso queira omitir o aviso da JVM sobre RESTRICTED METHOD (System.load), adicione a flag --enable-native-access=ALL-UNNAMED nas VM Options da sua configuração de execução no IntelliJ.2. Executando o Front-endNavegue até a pasta do front-end.Abra o arquivo index.html diretamente no seu navegador de preferência ou utilizando a extensão Live Server no VS Code / IntelliJ.✒️ Autoria e CréditosDesenvolvedor: [Evelyn]Instrutor:Átila: SENAIAno: 2026
